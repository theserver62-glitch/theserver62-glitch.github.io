1. 수집하는 개인정보

밀프렙 플래너는 회원가입이나 로그인이 없고, 이름·연락처·위치 같은 개인정보를 수집하지 않아요. 운영자가 따로 두는 서버도 없어서, 앱에 넣은 조건과 재료가 운영자에게 전송되지 않아요.

2. 이용자 기기에만 저장되는 정보

다시 열었을 때 이어서 쓰도록 아래 내용을 이용자 기기의 저장소에만 저장해요. 운영자는 이 정보를 볼 수 없어요.

  • 짜 둔 메뉴, 장보기 체크 표시, 최근 몇 주의 메뉴(같은 메뉴가 반복되지 않게)
  • 고른 언어

브라우저의 사이트 데이터 삭제나 앱 삭제로 언제든 지울 수 있어요.

3. 이용자가 직접 보내는 내용

장보기 탭의 ‘복사’·‘공유’를 누르면 장보기 목록 글이 복사되거나 휴대폰의 공유 창이 열려요. 이용자가 직접 고른 곳으로만 전달되고, 앱이 자동으로 보내지 않아요.

4. 외부 서비스

  • 쿠팡 파트너스: 장보기 목록과 준비물 옆 ‘쿠팡에서 보기’(광고 표시) 링크는 쿠팡 파트너스 링크예요. 누르면 휴대폰 브라우저에서 쿠팡이 열리고, 쿠팡이 구매 실적을 확인하려고 쿠키 등을 쓸 수 있어요. 밀프렙 플래너는 이 정보를 받지 않아요. 이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다 (쿠팡 개인정보처리방침).
  • 웹사이트 호스팅: 웹사이트판은 정적 파일만 제공해요. 접속할 때 호스팅 업체가 보안을 위해 IP 주소 같은 접속 기록을 처리할 수 있어요.

토스 미니앱에서만: 서비스 개선을 위해 쿠팡 링크를 눌렀을 때 "쿠팡 링크 누름"이라는 행동 이름, 누른 재료의 종류(예: 두부), 누른 위치(장보기 목록·준비물)만 토스(비바리퍼블리카)의 미니앱 통계로 보내요. 넣은 조건, 짠 메뉴, 이름 같은 개인정보는 보내지 않아요 (토스 개인정보처리방침).

토스 미니앱 광고: 결과 화면 아래에 토스(비바리퍼블리카)가 제공하는 배너 광고가 나와요. 광고를 보여 주고 성과를 세기 위해 토스가 기기·이용 정보를 처리할 수 있어요. 밀프렙 플래너는 그 정보를 받지 않아요 (토스 개인정보처리방침).

위 쿠팡 링크와 토스 미니앱 통계·광고 말고는 광고 도구, 분석 도구, 추적 쿠키를 쓰지 않아요. 웹사이트판과 Android 앱은 아무 행동 기록도 보내지 않아요.
